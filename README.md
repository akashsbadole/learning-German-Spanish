## 🇩🇪 German — Goethe A1 & A2 (जर्मन सीखें / जर्मन शिका)

German is the most spoken native language in Europe. These books follow the official **Goethe-Institut syllabus** and are written for Marathi/Hindi speakers — you will learn everything in **German → English → Hindi → Marathi** tables.

### What you learn at A1 (Start Deutsch 1)

| Area | Content |
| --- | --- |
| **Alphabet** | All 30 letters (A–Z + **Ä Ö Ü ß**) with Devanagari pronunciation |
| **Vocabulary** | ~350 words: greetings, family, numbers 0–100, food, house, time, shopping, travel |
| **Grammar** | Articles **der/die/das**, present tense of **sein/haben**, basic word order, question words |
| **Skills** | Introduce yourself, order food, ask directions, buy tickets, fill forms, write a ~30-word message |
| **Exam** | **Goethe A1** — 80 min, 4 sections, pass **60/100** |

### What you learn at A2 (Start Deutsch 2)

| Area | Content |
| --- | --- |
| **Vocabulary** | ~600–800 words: office, hospital, bank, renting, job interview |
| **Grammar** | Past tense (**Perfekt**), modal verbs (**können, müssen, dürfen**), prepositions, letter/email writing |
| **Skills** | Talk about daily life, describe past events, write ~40-word emails, make polite requests |
| **Exam** | **Goethe A2** — 105 min, 4 sections, pass **60/100** |

### Goethe exam structure (both levels)

| Section | A1 | A2 | Points |
| --- | --- | --- | --- |
| **Hören** (Listening — ऐकणे/सुनना) | 20 min | 30 min | 25 |
| **Lesen** (Reading — वाचन/पढ़ना) | 25 min | 30 min | 25 |
| **Schreiben** (Writing — लेखन/लिखना) | 20 min | 30 min | 25 |
| **Sprechen** (Speaking — बोलणे/बोलना) | 15 min | 15 min | 25 |
| **Total** | **80 min** | **105 min** | **100 — pass 60** |

**Useful for:** jobs in Germany, university study, family reunion visa, permanent residence.

## 🇪🇸 Spanish — DELE A1 & A2 (स्पॅनिश सीखें / स्पेनिश शिका)

Spanish is spoken by **500+ million people** in 21 countries. These books follow the **CEFR A1/A2** curriculum for the official **DELE exams** (Instituto Cervantes), written for Marathi/Hindi speakers.

### What you learn at A1

| Area | Content |
| --- | --- |
| **Alphabet** | 27 letters + special sounds (**ñ, ll, rr, j, z**) with Marathi/Hindi pronunciation |
| **Vocabulary** | ~300 words: greetings, family, numbers, food, house, shopping, time |
| **Grammar** | **ser/estar/tener**, regular verbs (-ar/-er/-ir), **gustar**, question words |
| **Skills** | Introduce yourself, describe a photo, fill forms, write a ~30-word message, order in a restaurant |
| **Exam** | **DELE A1** — ~100 min, 4 pruebas, pass **≥30/50 in each group** |

### What you learn at A2

| Area | Content |
| --- | --- |
| **Vocabulary** | ~500–700 words: work, health, city life, travel, past experiences |
| **Grammar** | **Pretérito perfecto** (past tense), future (**ir a**), comparatives, longer emails |
| **Skills** | Talk about your week, describe photos in detail, write 80–100 word emails, discuss plans |
| **Exam** | **DELE A2** — ~150 min, 4 pruebas, pass **≥30/50 in each group** |

### DELE exam structure (both levels)

| Prueba | A1 | A2 | Points |
| --- | --- | --- | --- |
| **Comprensión de lectura** (Reading) | 45 min | 60 min | 25 |
| **Comprensión auditiva** (Listening) | 20 min | 35 min | 25 |
| **Expresión e interacción escritas** (Writing) | 25 min | 45 min | 25 |
| **Expresión e interacción orales** (Speaking) | 10 min | 12 min | 25 |

**Pass rule (important):** results are grouped —
- **Group 1:** reading + writing → need **≥30/50**
- **Group 2:** listening + speaking → need **≥30/50**
- Both groups must pass — extra points in one group do NOT cover the other!

**Useful for:** jobs and study in Spain & Latin America, Spanish citizenship, international business.

## How to Use

1. **Read the PDF** or `*-Made-Easy-Project.md` first — it explains the full curriculum and workflow.
2. **Follow the Teacher's Guide** (`teacher-guide.md`) — two complete courses: **Course 1 = A1 (12 weeks)** and **Course 2 = A2 (12 weeks)** — week-by-week syllabus, top-100 frequency words, skills checklists and exam prep.
3. **Use** `lesson-template.md` to generate every chapter with an AI tool (ChatGPT, etc.).
4. **Practice** vocabulary from `vocabulary-starter.md`; use the flashcards and quizzes from the brief.
5. **Prepare for the exam** with `*exam-guide.md`, then take `mock-test-a1.md` and `mock-test-a2.md` with a stopwatch.
6. **View illustrations** by opening any `.svg` file in a web browser.

### Teacher's Advantages for Marathi/Hindi Speakers

| German | Spanish |
| --- | --- |
| Cases: **Dativ = दाता कारक** | 5 vowels = exactly Marathi vowels |
| SOV order → subordinate clauses feel natural | **me gusta = मुझे पसंद है** (same structure!) |
| **Sie/du = आप/तुम** | **usted/tú = आप/तुम** |
| Compound words like Hindi | **tener** + age = मेरी उम्र है |

### Quick Start with AI

Copy the master prompt from `lesson-template.md`, replace `{Chapter N}` with your chapter (e.g., "Chapter 4: Family"), and paste into an AI chatbot. Review the output with the Phase review prompt, cross-check translations with DeepL, then repeat for the next chapter.

### 6-Week Exam Plan (same for both languages)

| Week | Focus | Daily time |
| --- | --- | --- |
| 1 | Alphabet, sounds, spelling, greetings | 60 min |
| 2 | Numbers, dates, time, basic verbs (sein/haben · ser/estar) | 60 min |
| 3 | Vocabulary topic sets (15 topics), word order | 90 min |
| 4 | Reading + listening practice every day | 90 min |
| 5 | Writing: forms + short messages; speaking aloud | 90 min |
| 6 | Full mock tests (3×), weak-point revision | 2 hours |
