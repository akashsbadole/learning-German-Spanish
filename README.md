# Language Learning Books — Spanish & German (A1 → A2)

> Complete AI-ready book projects for **Marathi (मराठी)** and **Hindi (हिंदी)** speakers, covering **A1 → A2 (CEFR)** levels, including official exam preparation.

| Project | Language | Exam | Files |
| --- | --- | --- | --- |
| [`spanish/`](spanish/) | Spanish (Español) | **DELE A1 & A2** | 6 markdown + 20 SVG illustrations |
| [`german/`](german/) | German (Deutsch) | **Goethe A1 & A2** | 6 markdown + 12 SVG illustrations |

Both books follow the same structure: vocabulary with pronunciation, example sentences, translations in **German/Spanish → English → Hindi → Marathi**, grammar explained for Marathi/Hindi speakers, conversations, exercises, quizzes and flashcards — all produced chapter by chapter with AI.

### Exam coverage

- **German — Goethe-Zertifikat A1 (Start Deutsch 1) & A2 (Start Deutsch 2):**
  4 sections (Hören · Lesen · Schreiben · Sprechen), 100 points, **pass: 60/100**. A1: 80 min. A2: 105 min.
- **Spanish — DELE A1 & A2 (Instituto Cervantes):**
  4 pruebas (Comprensión de lectura · Comprensión auditiva · Expresión e interacción escritas · orales), 100 points, **pass: ≥30/50 in EACH group** (both groups must pass).

## How to Use

1. **Read** `*-Made-Easy-Project.md` first — it explains the full curriculum and workflow.
2. **Use** `lesson-template.md` to generate every chapter with an AI tool (ChatGPT, etc.).
3. **Practice** vocabulary from `vocabulary-starter.md`; use flashcards and quizzes from the brief.
4. **Prepare for the exam** with `*exam-guide.md`, then take `mock-test-a1.md` and `mock-test-a2.md` with a stopwatch.
5. **View illustrations** by opening any `.svg` file in a web browser.

## Quick Start with AI

Copy the master prompt from `lesson-template.md`, replace `{Chapter N}` with your chapter (e.g., "Chapter 4: Family"), and paste into an AI chatbot. Review the output with the Phase review prompt, cross-check translations with DeepL, then repeat for the next chapter.
