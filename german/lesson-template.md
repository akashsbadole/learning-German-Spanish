# Lesson Template — German Made Easy for Marathi & Hindi Speakers

> Reusable template for writing **every chapter** (Goethe A1 → A2).
> Fill in the placeholders and follow the structure below.

---

## 1. Master Chapter Structure (use for every chapter)

```
Chapter {N} — Topic: {TOPIC} — Goethe level {A1/A2}

Explain everything FIRST in Marathi, THEN in Hindi, then show German examples.

Include, in this exact order:

1. Theory (simple language, beginner-friendly)
2. German words — exactly 20:
   Columns: German | Pronunciation (Devanagari) | English | Hindi | Marathi
3. One daily conversation (6–8 lines) with:
   German | Pronunciation | English | Hindi | Marathi
4. Grammar notes for this chapter
5. 10 example sentences (German + English + Hindi + Marathi)
6. 10 exercises: fill blanks, matching, true/false, correct-the-error
7. 5 MCQ questions with answer marked ✔
8. 5 translation sentences (Hindi/Marathi → German)
9. Speaking practice (3 tasks)
10. Writing practice (1 task)
11. 10 memory tricks
12. Cultural tips about Germany

Rules:
- Pronunciation must use ONLY Devanagari script
- German must be 100% correct: umlauts (ä ö ü), ß, noun capitalisation
- Hindi and Marathi translations must be natural, not literal
- Add "Answer Key" for all exercises and MCQ
- Stay within Goethe A1/A2 syllabus
```

---

## 4. Quality Checklist (run after every chapter)

- [ ] Umlauts correct: ä ö ü (never ae/oe/ue in book text)
- [ ] ß used correctly after long vowels; ss after short vowels
- [ ] ALL nouns capitalised (der Tisch, die Schule, das Buch)
- [ ] ch soft (ich = इख) vs hard (Nacht = नाख्ट) — never च
- [ ] ei = आइ, ie = ई, z = त्स, v = फ, w = व, sch = श
- [ ] Articles der/die/das shown with every noun (color-coded memory)
- [ ] du (तू) vs Sie (आप) used correctly
- [ ] Hindi is हिंदी, Marathi is मराठी — never mixed
- [ ] Pronunciation column uses only Devanagari
- [ ] 20 vocabulary words per chapter
- [ ] All exercises have an answer key
- [ ] Goethe A1/A2 level respected (no past tense in A1 chapters)

---

## 5. How to Use (Phases 3–7)

1. **Phase 3** — use the Master Chapter Structure with Chapter {N} and {TOPIC} from the TOC
2. **Phase 6** — check the conversation is natural; fix translations
3. **Phase 7** — verify exercises; answer key must match
4. **Phase 12** — run the Quality Review checklist below
5. **Phase 13** — assemble into the book with the TOC

---

## 6. Quality Review Checklist

```
Review this German chapter for a book for Marathi/Hindi speakers.
Check:
1. German grammar, umlauts, ß, noun capitalisation (must be error-free)
2. English meaning accuracy
3. Hindi translation naturalness
4. Marathi translation naturalness
5. Pronunciation accuracy (Devanagari)
6. Goethe A1/A2 compliance
7. Exercise answer-key correctness
8. Table consistency (column order)
9. No English needed as bridge language

Report errors as: Location | Issue | Suggested fix
```
